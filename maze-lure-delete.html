계정 삭제 안내

길치 용사 키우기 (Maze Lure) · 개발자: niee

길치 용사 키우기의 클라우드 계정과 관련 데이터를 삭제하는 방법을 안내합니다. 계정 삭제는 게임 안에서 즉시 처리되며, 별도의 승인 절차나 대기 기간이 없습니다.

1. 게임 안에서 계정 삭제하기

  1. 게임 실행 → 마을(허브) 화면 상단의 구름(클라우드) 버튼을 누릅니다
  2. 계정에 로그인돼 있지 않다면 삭제할 계정으로 로그인합니다
  3. "계정 삭제" 버튼을 누릅니다
  4. 비밀번호를 다시 입력해 본인 확인하면 즉시 삭제됩니다

2. 앱을 설치할 수 없는 경우

앱을 이미 삭제했거나 기기를 사용할 수 없는 경우, smartmingue@gmail.com으로 가입 이메일 주소를 적어 계정 삭제를 요청해 주세요. 확인 후 7일 이내에 처리해 드립니다.

3. 삭제되는 데이터

데이터처리
계정 정보 (이메일 주소, 인증 정보)즉시 삭제
클라우드 세이브 (게임 진행 데이터 백업)즉시 삭제
랭킹 기록 (종합·무기별 순위, 닉네임)즉시 삭제

4. 보관되는 데이터

데이터보관 사유·기간
유료 결제(구매) 기록전자상거래 등에서의 소비자 보호에 관한 법률에 따라 5년 보관 후 파기
부정 이용 방지 기록 (이용 제한 이력)서비스 부정 이용 재발 방지 목적으로 보관

기기에 저장된 로컬 세이브는 서버와 무관하며, 앱을 삭제하면 함께 제거됩니다.
